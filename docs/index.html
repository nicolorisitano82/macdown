A fork of MacDown, for macOS 26

Markdown, with the parts that were missing.

MacDown is a fine editor that stopped short in two places: diagrams that did not draw, and exports that fell apart the moment someone else opened them. This fork finishes both, and brings the window up to macOS 26.

Download the latest release Source on GitHub Contribute

Requires macOS 26. Builds are unsigned — see opening an unsigned build.

What changed

Everything below is a thing that did not work, or did not exist, in the MacDown this grew out of.

Before

Graphviz destroyed the page. Its script wrote each graph over the whole document body, so everything else vanished — and it stopped redrawing after the first keystroke.

Now

Graphs replace their own code block and nothing else, and redraw as you type. Six layout engines: dot, neato, fdp, circo, twopi, osage.

Before

Mermaid 8.4.3, released in 2019, wired to window.load — so a diagram rendered once and reverted to a code block on the next keystroke.

Now

Mermaid 11.13, with the diagram types the 8.x line never had, redrawn on every edit and themed to match the system appearance.

Before

Word export lost most of the document. Pictures were dropped, tables flattened into tab-separated paragraphs, list indentation and code shading gone.

Now

Tables arrive as real tables, pictures arrive, code arrives monospaced — on Windows too, where the Mac font it used to name does not exist.

Before

The preview flashed on every keystroke, because it reloaded the entire page each time you typed a character.

Now

The rendered content is swapped in place. No reload, no flash, and your scroll position stays where you left it.

Diagrams you can actually read

A wide gantt chart or a large graph gets fitted to the preview pane until its labels collide. Every diagram now sits in a viewport you can move around.

Zoom

Pinch, or ⌃-scroll

Magnifies around the pointer, so the part you are looking at stays where you are looking.

Pan

Drag to move

Bounded, so a diagram cannot be flung off the edge and lost.

Reset

Double-click to fit

And the zoom survives a refresh, so you keep your place in a large diagram while you edit.

Exports that survive the trip

A file is only exported if it opens somewhere else. These are checked against Word, LibreOffice and epubcheck rather than against the app that wrote them.

Word

.docx with its structure intact

Real tables with borders and a repeating header row, pictures embedded, code monospaced and shaded, list indentation kept.

AppKit's Word writer provides none of that; each piece is repaired in the file after it is written.

EPUB

EPUB 3.3

Local images copied into the package, a table of contents built from the headings, and XHTML that readers accept.

Everywhere

Diagrams travel as pictures

Drawn into the HTML, Word and EPUB output, instead of shipping three megabytes of library and hoping the reader runs JavaScript.

And for writing

Prose

A prose checker, in two languages

Qualifiers, weasel words, hedging, wordiness, passive tells and repeated words — in English and Italian, including the bureaucratic inflations each language has of its own.

The word lists are a resource file. Extend or translate them without rebuilding anything.

Maths

A TeX editor with a live preview

Backed by a bundled MathJax, so formulas render with no network and nothing is fetched from a CDN as you type.

Links

WikiLinks

[[Another note]] links to a neighbouring document, and tells you when the file is not there.

Navigation

A sidebar with the outline

For moving around a long document by its headings.

Opening an unsigned build

No Developer ID certificate stands behind these builds, so macOS will refuse one on a double-click. After dragging the app to Applications: 

xattr -d com.apple.quarantine /Applications/MacDown.app

Whether to run an unsigned binary from the internet is your call. Building from source is the alternative, and takes about four commands.

Contributing

This is Objective-C and AppKit, and much of it is older than that suggests. If you have wanted an excuse to learn how a Mac document app is put together, this is a small enough one to hold in your head.

Get it building

Xcode 26 or later, for the macOS 26 SDK. The Command Line Tools cannot stand in for it.

git clone https://github.com/nicolorisitano82/macdown.git
cd macdown
git submodule update --init
pod install

Then open MacDown.xcworkspace — the workspace, not the project, which on its own has no pods.

Read the two pages that will save you a day

CONTRIBUTING.md has the house style and, more usefully, the traps: that the Debug build has its own preferences and a feature can look fine there and be dead in a release; that the preview does not re-run its scripts when it refreshes.

Pick something below, or bring your own

Open an issue for anything at all — telling apart a fault in this fork, in the original MacDown, and in a library underneath is rarely possible from the outside, and it is not your job to.

Worth doing

Honest about size. The first is a project; the last is an afternoon.

Large

Move the preview to WKWebView

It still runs on WebKit's legacy WebView, deprecated since macOS 10.14. Word count, scroll syncing, the MathJax bridge and printing all reach into the page synchronously, and the modern API is asynchronous — so each has to be rewritten. It is the largest thing left, and everything else gets easier afterwards.

Medium

Make maths survive an EPUB export

Scripts are stripped from the package, quite rightly, so TeX is left visible as its source. The fix is the one already used for diagrams: take the SVG MathJax has drawn in the preview and inline it.

Medium

Decide what language the prose checker speaks

Its categories are named in English even while flagging Italian. Translating them means choosing whether the names follow the application's language or the document's — and the second needs to know what language a document is in.

Small

Grow the word lists

They live in MacDown/Resources/Data/prose-issues.json and need no code, no rebuild, and no Objective-C. A new language is a pull request against one file.

Not code

Sign the releases

Every download currently asks the person who made it to strip a quarantine attribute by hand. Fixing that needs an Apple Developer account, not a patch.
