fianco: ognuno è scritto per mostrare cosa fa la funzione, non solo per
descriverla.

I riferimenti qui sopra sono WikiLinks: se sono attivi nelle preferenze
diventano collegabili, altrimenti restano testo.

## Preferenze che servono

Quasi tutto funziona senza toccare niente. Le eccezioni:

- **Evidenzia la sintassi nei blocchi di codice** — spenta per impostazione
  predefinita, serve per `01-markdown`
- **Sintassi delle liste di attività** — serve per le caselle in `01-markdown`
- **Rileva il token del sommario** — serve per `08-sommario`
